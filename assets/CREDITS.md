# 에셋 출처

Pokemon © Nintendo / Creatures / Game Freak — 학교 내부 교육용으로만 사용합니다 (상업적 이용·외부 배포 금지).

| 파일 | 출처 |
|---|---|
| `enemies.webp` / `enemies.json` | 4방향 걷기 시트(하트골드 동행 포켓몬 스타일) — [baptiste-ro/pokemon-followers-sprites](https://github.com/baptiste-ro/pokemon-followers-sprites) (일부는 환경몬고 로컬 캐시 사본) |
| `bosses.webp` / `bosses.json` | 5세대 전투 정면 애니메이션 — PokeAPI sprites (gen5 animated), 환경몬고 `public/assets/pokemon/anim` 캐시에서 프레임 추려 재배치 |
| `fx.webp` / `fx.json` | 기술 이펙트 이미지 — [Pokemon Showdown](https://github.com/smogon/pokemon-showdown-client) `fx/` (환경몬고 `battle/psfx` 캐시) |

재생성: `/usr/bin/python3 scripts/build_pokemon_atlas.py`
